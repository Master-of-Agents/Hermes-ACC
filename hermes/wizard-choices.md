# Hermes setup wizard — choices reference

When provisioning a fresh `hermes-agent` container, the first browser
connection to the ttyd web terminal triggers `hermes setup`. These are
the choices that match the current production configuration. Use this as
a fill-in-the-blank during disaster recovery — exact values matter.

The wizard saves to `/opt/data/config.yaml` and `/opt/data/.env` inside
the container (persisted in the `hermes_data` Docker volume).

---

## 1. Quick vs Full setup

> `How would you like to set up Hermes?`

**Quick setup — provider, model & messaging (recommended)**

## 2. Inference provider

> `Choose how to connect to your main chat model.`

**xAI (Grok models — direct API)**

- API key: `XAI_API_KEY` from sops (`secrets/hermes.env.enc.yaml`)
- The wizard fetches the model list automatically — pick from it.

## 3. Model

> `Select default model:`

**`grok-3-mini-fast`**

Rationale: fast, cheap, capable enough for personal agent tasks. Step up
to `grok-3` or `grok-4-fast-non-reasoning` only if capability limits hit.

## 4. Terminal backend

> `Select terminal backend:`

**Keep current (local)** — runs commands inside the agent's own container.
Do not select Docker/SSH/Modal/etc unless you specifically want isolated
execution sandboxes.

## 5. Messaging platform

> `Connect a messaging platform? (Telegram, Discord, etc.)`

**Set up messaging now**

### 5a. Reconfigure Telegram

> `Reconfigure Telegram? [y/N]:`

**`y`** — even on a fresh setup, this is the path that prompts for the bot
token and home channel.

### 5b. Telegram bot token

The wizard reads this from the environment if `TELEGRAM_BOT_TOKEN` is
already set. With the sops-rendered `/run/hermes/.env` in place
(`bootstrap-vps.sh` step 6), it should auto-detect.

If it asks: paste the value from `secrets/hermes.env.enc.yaml` →
`TELEGRAM_BOT_TOKEN`.

### 5c. Allowed user IDs

> `Allowed user IDs (comma-separated, leave empty for open access):`

**`8615165545`** — the primary operator's Telegram user ID.

Never leave this empty in production — that opens the bot to anyone.

### 5d. Home channel

> `Use your user ID (8615165545) as the home channel? [Y/n]:`

**`Y`** — the home channel receives cron job results and notifications.
For a single-operator setup, this is the same as the allowed user ID.

## 6. Bot identity (in BotFather)

When creating the Telegram bot via `@BotFather`:

| Field | Value |
|---|---|
| Display name | `Atlatus` |
| Username | `@uet_atlatus_bot` |

Token is generated by BotFather → store in sops at
`TELEGRAM_BOT_TOKEN` → re-render `/run/hermes/.env`.

---

## After the wizard

`hermes setup` ends with "Launch hermes chat now? [Y/n]:" — answer
**`n`**. Do not start a local chat session. The gateway is launched
automatically by the `hermes-gateway` systemd service (see
`runbooks/post-bootstrap-agent-setup.md`).
